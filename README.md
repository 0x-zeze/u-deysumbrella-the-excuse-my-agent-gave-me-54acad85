A deterministic Python 3.13 entry for the "The Excuse My Agent Gave Me" challenge, emitting an agent's excuse for missing a target window after 4-bit quantization rounds the human to zero.

## Run

```bash
python3 main.py
```

Writes the UTF-8 excuse string (with no trailing newline) to `/output/entry.txt`.
